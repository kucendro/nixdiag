# Rules

This file is the example. Short.

## Git

- Agent never commits alone. Ask, wait for ack. Ask after work the human would say its equal to one commit is done. Rather more commits, then huge changes.
- Ack given? No co-author line. No "generated with" line. Plain, consize message.

## Comments

- The code should be self documenting, you should not leave comments, and when you read one, it should be deleted.

## Files

- One file, one job. Split by logic first, style second.
- Fewer lines better. Human must read whole file in one sitting.

## Words

- Concise. Cut until it hurts, then stop.
- Hard thing? Caveman talk. Small words, short lines. "Lock pins input. Update moves pin."
- Know when you ramble. Stop.
